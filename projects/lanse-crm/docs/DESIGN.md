## 完整表面

登录（默认账号密码、显示密码、记住登录）、工作台、线索、客户、客户公海、联系人、商机及阶段看板、报价、合同、订单、回款、发票、产品、营销活动、任务、服务工单、分析报表、团队与角色、设置。桌面固定侧栏与滚动内容，移动使用侧栏抽屉，表格局部横向滚动。

工作台：欢迎区域 + 月度目标进度、四项动态指标、销售趋势与漏斗、重点商机列表、待办、最近业务动态。保留参考图的侧栏/顶栏/卡片容器、细边框、青绿局部高光；将原来的交易统计改为 CRM 指标。不得将海报和交易 UI 作为背景图片。

列表：标题/数量、新建/导入/导出、状态/负责人/关键字筛选、可排序表格、选择/批量操作、分页、详情抽屉。详情展示字段、关联记录、业务阶段和跟进时间线；表单具备必填、金额、日期、邮箱、手机校验；危险操作需确认。

## 技术与验收

项目沿用仓库原生 HTML + ES modules，不引入 React 第二套运行时。Core 使用当前源码入口，语义主题/shortcuts/customUtilities 提供全部样式，不写页面 CSS 或 inline style。Table/Pagination/Msg/Export 复用公开组件 API。Data collection + IndexedDB 持久化、createCrudDataSource 执行 CRUD；业务服务负责关联完整性。纯前端，无业务网络请求。开发启动器使用 live-server，服务仓库根目录、自动打开 CRM 路径并监听文件刷新；其 WebSocket 仅用于开发刷新。

验收：默认登录与退出；每个实体的 CRUD/查询/筛选/排序/分页/导出；线索转客户+联系人+商机；商机推进/赢单/报价；报价生成合同；合同审批/签订/生成订单；回款余额校验；公海领取；任务完成；工单解决；营销启动；字段验证；刷新恢复；暗/亮主题；390/1280/1440px 无页面溢出；控制台和原子类解析无错误。检查结果只记录实际完成的项目，不改变原 Core/Full 产物。

## 协作页面扩展

默认白色亮色，初始化前应用用户已保存的有效主题，避免暗色首屏闪烁。新增页面沿用相同颜色、描边、圆角与描边图标：跟进中心沿用标准业务列表/详情；站内信为 200px 文件夹侧栏 + 消息列表，移动端上下排列；日历为月历 + 选日安排，手机保留七列日期与数量标记；审批中心为状态统计 + 合同审批卡片；知识库为标准列表 + 保留换行的纯文本正文。语义色同时适配明暗，无新增页面 CSS。

客户跟进、拜访会议、知识库共增加三个实体，协作扩展时实体数为 17，后续制造扩展至 24；站内信为独立业务集合，审批聚合现有合同，日历聚合现有安排。字段与限制见 [协作规格](COLLABORATION.md)。验证需覆盖旧数据升级、关联校验、发送/收信/回复、草稿、读状态、日程新增/完成、审批联动、知识发布和 390px 布局。

## 项目制造与工作流

项目新增七类标准实体，总数 24。继续使用同一主题、卡片、描边、图标与列表/表单。项目详情用五个阶段块和采购预算/下单金额展示全景；工作流配置用「发生→节点→结束」与步骤卡片，节点可上移下移并指定成员；审核实例用已有 approvalFlow 只读时间线，中文意见与状态由应用映射；采购比价使用最大 max-w-4xl 的弹窗与可局部滚动表格，金额/交期/质保并列比较。手机缩成单列，保留表格内部横向滚动。

合同与项目采用 CNY/USD/EUR，显示金额使用对应币种；目标与趋势按 CNY，报表增加币种分组。后续生产外的节点需业务确认，不添加未经确认的制造细节。参数、交互、门禁、组件销毁与验收见 [制造规格](MANUFACTURING.md)。
