# 项目制造与审核工作流 Implementation Plan

> 在当前会话完成实现与验证。用户已批准项目管理与可配置工作流方向，不再增加实施审批环节；仓库无 Git，直接在现有项目工作。

**Goal:** 以海外船舶订单样例串联项目立项、设计审核、采购拆分、供应商询报价、方案审核和生产准备。

**Architecture:** 保持原生 ES modules、语义主题和 JquanUI Data；标准实体复用 schema 表单与 Table/Pagination。独立 workflow 服务维护模板快照、审核节点、记录锁定和本地站内信；manufacturing 服务维护项目关联与采购评估。现有合同审批保持可用，新增项目审核使用统一实例。

**Tech Stack:** JquanUI Core / Data / Table / Pagination / Msg / Export、原生 dialog、IndexedDB、Edge CDP。

## 实施步骤

1. 扩展 schema/seed：项目、设计任务、采购需求、供应商、询价单、供应商报价、生产计划；新集合自动初始化，海外样例所需客户/合同只增补一次，保留用户已有数据。
2. 新增 workflow.js：模板 CRUD、启停、节点顺序/审核人、提交/自动触发、通过/退回/驳回、待办与历史；业务记录提交锁定，重新提交创建新实例，流程快照不随模板编辑变化。
3. 新增 manufacturing.js：合同与币种一致、设计门禁、拆分多笔采购、向多供应商发询价、报价关联/版本、评估理由与选定方案、审核后下单、全部采购下单后安排生产。
4. 扩展 app/overlays：导航、流程配置器、统一审核中心、项目全景、采购比价表和业务动作；支持切换当前成员查看审批待办与站内信；原有 CRM 模块保持正常。
5. 外贸字段：合同/项目国家、币种、交付和付款条款；采购使用项目币种。外币不与人民币混加，财务记录继承合同币种，报表显示各币种合计。
6. 业务验收：多级流程当前审核人、越权/重复提交、审核中编辑锁定、退回修改与重提、快照、采购拆分与询价去重、报价版本和选择、生产门禁、刷新恢复和删除保护。
7. 界面验收：亮暗主题与 390/1280/1440px；无页面级 CSS/inline style；Core failedRuleCount=0。
8. 同步 README/DESIGN/MANUFACTURING、本项目 skill、根项目文档与 jquanui/DATA skill；运行项目 check、既有 131 项回归及制造专题回归、build/portable、根 check:docs。

## 范围

流程仅覆盖客户已经说明的生产前阶段及生产状态，不编造试航、交付和质保细节。报价评估采用金额、交期、质保与说明，不自动替代采购决策；无外部消息、金蝶接口、汇率服务或业务后端。工作流配置为顺序审核节点，支持 1–5 级；暂不提供任意脚本、分支表达式与并行会签。
