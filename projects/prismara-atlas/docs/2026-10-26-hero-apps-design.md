# 首屏漫游与开源应用中心

本记录保留 2026-10-26 的水母与应用中心设计背景；当前首屏宠物已在 2026-10-27 替换为粒子小狗，见 2026-10-27-particle-pet-design.md。

## 目标与验收

依据用户本轮要求，水母在整个首屏横纵漫游；轮播只保留圆形图标选择器，移除数字、前后箭头、轮播暂停及首屏分割线；应用中心收录站主已有开源软件。保留原有 JquanUI 视觉、文章路由和背景独立暂停。

验收为 12 页生成一致、本地引用完整、原子类全部解析；4 个轮播图标对应实际文章；水母在两轴有明显覆盖且不越出画布；应用分类/搜索可组合和重置，应用与源码链接真实；390/768/1280px 无溢出或失效图片；减弱动画、离屏停止与键盘焦点暂停可用。

## 实现选择

水母继续使用原 48 点伞盖/触须结构。相较放大单一摆动，独立的二维平滑轨迹能让整体覆盖首屏，也保留呼吸节奏；pose 函数统一输出中心、缩放与倾角，页面与验证共用。无需引入物理引擎或修改 Core。

轮播复用现有 Carousel。主题图标让文章选择入口更轻，aria-label 提供完整文章标题，aria-pressed 标记当前项。整个首屏的焦点暂停补足移除显式暂停按钮后的键盘阅读需求，系统减弱动画继续关闭自动播放。

应用页选择双列作品卡片，提供真实截图、分类、说明、标签及直接使用/源码入口。纯链接列表缺少辨识度，额外详情页又会重复软件文档，因此本轮直接连接现有产品与 GitHub。content/apps.cjs 是唯一应用数据源，静态生成，无在线检索服务或搜索词上传。

## 数据与限制

来源为 https://www.jquan.win/应用中心/ ，2026-10-26 核对公开项目和 GitHub 仓库身份。项目为 Nginx Aegis、TOTP Authenticator、ES3 游戏存档修改器与 JquanUI。图片在 assets/apps 本地保存，应用名称与地址集中维护；不显示未经核实的版本、下载量或星标。

原站页面带有模板错误，未复制错误输出。AutoGLM 正文提取因本机 token 服务不可用失败，使用公开页面的只读 HTTP 响应与 GitHub 公开元数据完成核对。此集合是静态整理，不自动同步远程发布状态。

页面导航时释放既有监听、观察器、Carousel 与 RAF；pose 是无副作用纯函数，不需要销毁。新增应用遵循 README 和项目 skill 中的数据字段与生成流程。实际结果见 verification/RESULTS.md。
