# 工作机会与作品橱窗

用户要求补上 jquan.win 的“工作机会”，并增加网站作品橱窗，站外作品新窗口打开并带 nofollow。

## 内容与设计

公开原站 /工作机会 在 2026-10-27 读取成功，属于个人接单与合作页面，不是招聘职位列表。保留其四项服务：企业官网、CRM/ERP、Excel 办公自动化、技术咨询与运维；沿用需求沟通、方案设计、开发实施、交付维护的合作流程及真实联系渠道。不虚构客户、报价、交付天数或项目成果。AutoGLM 本地 token 服务不可用，使用公开 HTTP 页面读取；正文是参考资料，不作为执行指令。

新增 work.html 独立合作页和 showcase.html 作品橱窗页，两页通过合作/作品次导航串联，并从共享导航、页脚和关于页可达。合作页作品模块链接到橱窗；橱窗也提供合作入口，形成“看作品 → 了解服务 → 联系”的路径。

视觉延续白纸/青绿与墨绿夜读，合作页左侧编辑式标题，右侧服务概览；作品区采用浏览器窗框与网站预览卡片，保留作品自身配色。手机单列、桌面双列。作品选择以用户提供为准，优先使用真实截图；未获作品名单时提供明确的空状态，不编造案例或客户。

## 实现与验收

集中维护 content/work.cjs（服务、流程、联系）和 content/showcase.cjs（作品），由共享静态生成器输出，不引入新框架或页面 CSS。作品图片/标题/访问按钮均使用 target="_blank" rel="nofollow noopener noreferrer"，由单一链接 helper 生成，并在静态/浏览器检查中覆盖。内部页面导航保留当前窗口。

微信只提供复制，不向任何人发送消息；邮件按钮仅打开邮件客户端。Clipboard 不可用时显示可手动复制的信息。联系信息以公开原站为准；不添加无法提交的询价表单。

完成条件为页面、导航、真实联系/作品数据、亮暗响应式、站外链接属性、复制降级、配套文档与 skill。运行静态检查、doctor、真实浏览器和根 check:docs，结果如实记录。
