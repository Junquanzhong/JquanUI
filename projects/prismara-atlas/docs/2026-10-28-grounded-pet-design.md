# 四脚粒子小狗与自主玩耍

用户要求真实脚步、趴地、刨土、屏幕边缘抬腿、追蝴蝶、头顶气球；光标进入首屏立即中止玩耍，看向光标、跑来并蹭蹭。沿用现有 JquanUI 页面、Carousel、Canvas 插画与亮暗主题，不引入宠物后台或新框架。

## 设计与实施

1. 将 prismara-motion.js 的悬浮前视犬改为稳定的侧视垂耳四脚犬，保留 64 个主体粒子。自主目标走在首屏轮播区域内部的浅景深地面，脚底阴影与接触点说明地面；高处光标只影响头眼方向和地面目标，不令小狗悬浮。四条腿用与位移关联的步态，停下后停止踏步，跳跃只用于顶气球。
2. 用独立实例与 elapsed 驱动行为：漫步、趴地、刨土、到边缘后抬腿、追逐有独立轨迹的蝴蝶、走到气球下后跳起碰球。动作间平滑起身/降低头部，轮换路线和边缘；不在每帧随机更换动作。光标优先级最高，先短暂注视，再跑近，停留后摇尾、抬爪和蹭蹭；任何玩耍都可中断，移出恢复自主玩耍，无位置跳跃。
3. 抽离 prismara-pet-renderer.js 管理 Canvas 粒子、四脚连线、阴影、泥点、蝴蝶、气球和轻微抬腿粒子；模型输出可测试的脚点、头部、地面、动作、玩具状态。页面只负责 RAF、Canvas、指针/可见性与销毁。玩具是本地绘图，无远程图片。
4. 延续 30fps / DPR 1.5、首屏范围、触屏不跟随、装饰层点击穿透、暂停/离屏/后台/减弱动画取消 RAF。elapsed=0 不推进任何行为或物理状态，主题重绘保持动作和位置。缩小窗口先夹紧位置与绘图边界。玩具颜色进入主题语义令牌。

## 验收

修改前静态基线通过：18 页 / 888 引用 / 12 语法检查。实现后静态为 889 引用 / 13 语法检查，doctor 为 313 个 class token / 438 条规则。更新 Node 模拟：四脚步态与位移、停步、全部自主动作、到边缘后才抬腿、跳起确实触球、任意动作被光标打断、抬头注视、跑来撒娇、离开恢复、零步长冻结、窄屏边界和尺寸变化。真实浏览器截图覆盖动作与亮暗、手机、暂停/减弱/离屏/触屏与点击穿透：六个动作各截取 light/dark × 390/1280，继续跑全站 108 组。同步 README、视觉说明、项目 skill 与验证记录，根 check:docs 和 doctor 均通过后交付。

用户纠正：小狗属于首屏背景板，不单独占用布局空间。已撤掉为宠物增加的底部留白，恢复 py-10 / sm:py-14，Canvas 保持绝对定位覆盖首屏，四脚与所有玩耍仍在内部地面坐标完成。

地面深度范围改为 Canvas 高度的 60%–84%（保留犬形顶部安全余量），让小狗在轮播内部活动，而非挤在轮播下方；不会因此增加 DOM 高度。
