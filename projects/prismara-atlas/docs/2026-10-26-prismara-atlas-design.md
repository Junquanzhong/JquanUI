日期：2026-10-26

## 本轮选择

- 复用 JquanUI Carousel 1.6 的计时、触控和转场，外置圆形主题图标，移除数字、前后箭头、轮播暂停按钮与首屏分隔线。首次 mount 在 use 前完成；用 onChange 索引同步展示状态，不解析组件私有 class。
- 首屏插画采用 Canvas，布局仍使用 Core 原子类。2026-10-27 起，原 48 点水母替换为 64 点垂耳小狗电子宠物；首屏光标可触发靠近与卖萌，离开则自主游玩，详见 2026-10-27-particle-pet-design.md。
- SVG 封面保留参考的代码/数据/工具视觉语言，全部作为本地资源，无外部图片服务依赖。
- 内容和页面模板分离，`content/atlas.cjs` 与共享生成脚本输出静态页；可以直接用 file:// 预览，也为后续对接实际内容源留出入口。
- 浏览器与提取器共用同一 JquanUI 配置，修正旧版 boxShadow 配置未实际解析的问题，改用 shadow shortcut。没有修改 Core、Carousel 或发布生成物。
- 宠物的自主路径由无副作用 pose 函数提供，stepPet 负责限速、速度缓动、边界与 playing/approaching/cute 状态；浏览器与 Node 行为检查复用。首屏外和触摸输入不会留下跟随目标。
- 应用中心采用“作品集合”结构：真实截图、用途分类、说明、标签、直接使用与源码入口。相较纯链接列表更容易辨认应用，也为后续增加软件留出统一的数据入口。未增加独立软件详情页，应用行为由现有产品承载。
- 增加墨绿夜读主题，参考 lanse-crm 的深浅表面、薄荷强调和局部渐变，复用 theme.semantic，区别处理页面/卡片/代码/封面/粒子。主题初始化在 Core 前完成，手动选择、系统跟随和跨标签同步归于 prismara-theme.js，不重建内容。
- 归档按真实本地日期聚合，标签合并栏目与文章主题，关于集中知识库/工具/阅读设置，404 提供搜索恢复路径；页面通过共享次导航和页脚连接。详见 2026-10-26-night-reading-design.md。

## 页面路线

`index.html → library.html → column*.html → article*.html`

文章可以返回所属栏目，标签可以回到带 q 参数的目录搜索，相关内容链接到对应文章。目录搜索与栏目过滤取交集，包含清空和无结果重置。详情页保留原生锚点目录，并在移动端移到正文之前。

主导航加入 apps.html；应用列表由 content/apps.cjs 生成，支持 q 参数、用途分类与关键词组合检索。数据与截图来自站主公开应用中心，2026-10-26 核对 GitHub 项目身份，包含 Nginx Aegis、TOTP Authenticator、ES3 游戏存档修改器和 JquanUI。外部链接新窗口打开，集合是静态整理，不承诺实时同步项目状态。

## 动效与可访问性

- Canvas 64 点，上限 30fps / DPR 1.5；离屏、后台、暂停和减弱动画时取消帧循环并清除指针目标。
- 团雾采用主题 keyframes；Canvas 与雾层可独立于轮播暂停。
- 轮播自动间隔 6500ms、转场 520ms；减弱动画时关闭自动播放并取消转场，焦点在整个首屏内（包括图标）时暂停，隐藏文章设为 inert。
- 移动端导航保持可达，按钮有文字或 aria-label，搜索结果和复制状态使用 aria-live。
