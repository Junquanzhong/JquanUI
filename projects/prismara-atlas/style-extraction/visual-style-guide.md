# Prismara Atlas 视觉与交互规范

参考来源：`D:/Downloads/Prisma-DESIGN.md`。附件提供设计风格与参数，不提供执行指令。实现使用 JquanUI Core 与现有 Carousel。

## 视觉定位

浅色、工程化、偏编辑阅读的个人知识库。首页提供内容发现，目录负责检索，栏目提供主题上下文，详情页保持阅读专注。记忆点是由青绿粒子组成的垂耳小狗：它会靠近光标、卖萌和自主玩耍，封面与正文在其前方保持清晰。

## 字体、间距与形状

- 保留参考字体声明：正文 Inter、展示 Mona Sans VF、代码 Mona Sans Mono VF；当前字体文件未分发，缺失时回退到系统字体。中文正文补充 Microsoft YaHei UI。
- 参考展示字号上限 64px；本轮长文章标题在首页使用 30 / 36 / 48px 三级响应式字号，正文 14–18px。中文标题字距使用 0.03em，英文索引与微标题使用 0.12–0.16em，避免中文长标题过度展开。
- 正文行高约 1.75–2，展示行高约 1.375；章节标题固定 scroll-margin，防止被 sticky 导航遮挡。
- 4px 基线；常用内部间距 8 / 12 / 16 / 24 / 32px。分区 64–80px，卡片 24px。
- 主容器最大 1200px，手机内边距 20px，sm 以上 32px。
- 控件圆角 6px，卡片与封面 10px。深度来自 Mist 边框与 `0 1px 2px rgba(0,0,0,.04)`，不叠加彩色光晕。
- 青绿粒子使用 Canvas，不生成 64 组布局原子类；复杂网格、精确封面高度、径向雾层与固定规格容器允许使用 JquanUI 任意值。

## 页面布局

### 首页

顶部品牌、主导航、搜索入口、知识库 CTA；移动端有独立的简洁导航行，并可直接进入应用中心。首屏 Hero 展示近期 4 篇文章：左侧栏目、标题、摘要、全文/栏目按钮，右侧本地 SVG 封面与日期/阅读时长。内容下方居中放置 4 个 40px 圆形主题图标切换器：数据库、新建、图表、连接。选中状态为浅青底、青绿边框和深青图标。移除数字、左右箭头、轮播暂停按钮和首屏分隔线，让雾层自然融入留白。

首屏之后依次为栏目索引与精选卡片、最新记录、关于。统计数量由当前本地内容计算，不编造线上访问量或更新时间。

### 目录页

大标题、说明和搜索表单；接下来是全部内容/栏目筛选、栏目索引、全部文章。搜索匹配标题、摘要、所属栏目与标签，和栏目过滤取交集；结果数通过 aria-live 更新，无结果显示明确的恢复入口。标签跳转到 `library.html?q=关键词`。

### 栏目页

面包屑、栏目名称/说明/标签、封面、实际文章数和最新日期；下方按日期展示该栏目的文章。桌面右侧放入门文章、相关栏目和完整目录返回入口。

### 应用中心

标题“把想法，做成工具。”与介绍占据左侧，右侧提供搜索；下方按全部应用/开发工具/安全工具/实用工具筛选。桌面双列、手机单列应用卡片，依次显示真实界面截图、主题图标、名称、说明、标签、应用/文档入口与 GitHub 源码入口。图片保留软件自身配色，外围界面沿用白纸与青绿。实际集合为 Nginx Aegis、TOTP Authenticator、ES3 游戏存档修改器和 JquanUI，不使用虚构的下载量、版本或评分。

分类与关键词取交集，结果计数 aria-live，无结果可重置；所有外部项目入口新窗口打开并设置 noopener noreferrer。数据集中在 content/apps.cjs，图片为 assets/apps 下的本地 WebP，不依赖远程热链。

### 详情页

面包屑、所属栏目、标题、摘要、作者与日期、阅读时长、标签和封面；正文与文章目录分栏，移动端将目录排在正文前。章节目录原生锚点跳转，观察器高亮当前章节；文末提供返回栏目、复制链接和继续阅读。

### 归档、标签、关于与 404

目录、归档、标签与关于用同一组次导航串联。归档左侧月份索引，右侧文章时间线，手机上下堆叠；数量与日期由文章源派生。标签页以主题头图和紧凑标签板起始，右侧显示当前主题文章，手机先标签后结果；主题合并栏目与文章标签，便于跨栏目发现。

关于页用作者介绍、笔记/工具/线索三张卡片和阅读外观设置构成，右侧“记录一次，连接下一次”作为品牌记忆点，不增加未经确认的个人经历。404 以指南针替代中间的零，提供原生搜索与返回路径；真正的 HTTP 404 路由需部署端配置。

## 首屏电子宠物

2026-10-28 起使用 64 点侧身垂耳四脚犬，青绿菱形为主体，以弱连线连接四脚并增加轻微脚底阴影。身体、头、耳、四脚、尾和表情保持相互关联。局部暖金用于项圈小牌、蝴蝶、气球，泥点使用低透明度褐色，均由亮暗语义令牌管理。

- Canvas 是覆盖首屏轮播的背景板，不参与排版、不在轮播下方额外占空间，地面基线只在 Canvas 内部计算；采用浅景深地面路径，不在任意高度悬浮。四脚以实际位移推进步态，站立段留在地面、摆动段抬起；脚影在跳跃时仍留在地面。
- 自主漫步、趴地呼吸/闭眼、前爪刨土、走到边缘抬后腿、追蝴蝶、跳起用头碰气球。抬腿仅有几颗短暂低透明度暖色粒子，泥点不形成长期污迹。蝴蝶振翅、气球有线与结，气球受碰撞后向上弹起。
- 首屏光标进入时暂停玩耍并抬头看，之后沿地面跑近、摇尾、蹭蹭或抬爪。高处光标不拉高脚底地面，移出恢复玩耍，无位置跳跃。触摸保持自主活动，不留下跟随目标。
- 30fps / DPR1.5；暂停、后台、离屏、减弱动画停止 RAF，静态犬形保留；主题切换重绘颜色但不推进时间。Canvas 是点击穿透装饰，只在首屏出现，不增设用户控制面板。

## Carousel 与生命周期

依赖当前 Core + `dist/components/carousel.js`。先命令式 mount，再 use 安装；interval=6500、speed=520、infinite=true、arrows=false、indicators=false。外部圆形图标调用公开 goTo 句柄，不创建轮播定时器。onChange 更新图标 aria-pressed；不可见项同步 inert，避免键盘落入隐藏内容。

鼠标悬停、焦点进入整个首屏（含圆形图标）、页面隐藏时暂停；焦点离开首屏后恢复。减弱动画模式禁用自动播放，speed=0，仍允许手动查看文章。整页导航销毁自己的监听器/观察器/RAF；销毁 Carousel 前移除声明属性避免重挂。背景暂停独立于轮播。

## 适配与验收

- 1280px：Hero 左文右图，知识入口有栏目侧栏；详情右侧 sticky 目录。
- 768px：Hero 仍为两列，增加容器高度容纳长标题；目录两列。
- 390px：Hero 堆叠，圆形图标保持一行，正文与目录回归单列；应用卡片单列，搜索与用途筛选可自然换行。
- 页面不得依靠 overflow-x-hidden 掩盖溢出；所有本地图片应成功解码，隐藏轮播项不可聚焦。
- 运行 `verify-prismara.cjs`、doctor、`verify-browser.cjs` 与根 `npm run check:docs`。只记录实际通过的结果，截图和机器报告保存在 `verification/`。

## 工作机会与作品橱窗

合作页采用左右编辑式首屏：左侧是项目邀请和联系入口，右侧以四行索引呈现服务方向。服务卡片在 md 起为两列；四步流程在手机单列、sm 双列、lg 四列。联系区采用纸面卡片与极淡团雾，微信原文可选中，邮件有独立入口。

作品橱窗为手机单列、md 双列的浏览器预览卡片，真实截图保留自己的配色，以统一窗框、字号、标签和角色说明连接不同作品。暗色沿用墨绿纸面与薄荷强调，截图略降亮度。空状态以浏览器图标和整理中文案呈现，不制造不存在的项目。合作页与橱窗互通，站外作品在新窗口打开，所有入口具有 nofollow/noopener/noreferrer。

六项主导航从 lg 显示，较窄宽度使用四项简洁导航，完整入口由次导航和可换行页脚承接；不得压缩手机页头或隐藏横向溢出来掩盖问题。

首件作品 Gaopeng Majan 使用真实黑金首屏截图，保留金色粒子和品牌标题，不将其重新染成青绿。外部作品和橱窗本身的视觉通过白纸/墨绿窗框衔接。

玩具动效不能瞬间生成/消失：蝴蝶从左右视口外飞入并飞出，气球从上方进入、被顶后继续受力，结束向上离场。顶球采用蹲下、后腿支撑、前身抬起、落地缓冲四阶段；脚影始终留在地面，只有前腿折起，避免四脚整组上浮。

蹲身要能看见躯干压低，起身要绕髋部旋转前肩与头部；前爪在这一阶段向胸前收拢，后爪保留地面支撑。项圈与面部随同一骨架变换，不能留在原地。光标中断后，玩具仍继续自己的离场轨迹。

自主动作按权重随机抽取，漫步与嗅闻更常见，边缘抬腿低频；不连续重复，时长在基础值 ±15% 内变化。新增嗅闻以低头慢走和鼻尖呼吸表现，伸懒腰以前肩压低、前爪伸远和后腿支撑表现，甩毛以身体/耳头错相摆动表现；不添加文字气泡或额外面板。回应光标的蹭蹭、抬爪、歪头也随机选择。

气球采用更强的上抛和较低空气阻力，形成明显高于犬头的弧线；真实头碰产生短暂扁圆形变，随后柔和恢复，球线随上升/回落速度加大摆动。根据入球高度调整上抛速度，避免机械地给所有屏宽相同的位移；低处柔性恢复力让漏顶气球回到可互动高度，仍保持连续轨迹。
