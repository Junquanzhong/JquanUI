# 澄光编辑台视觉规范

## 视觉定位

澄光编辑台是一套偏内容门户和编辑部工作台的 B 端界面。它的记忆点不是复杂的数据图表，而是让内容、摄影图片和阅读层级成为主角。界面保持轻、净、安静，蓝色只承担导航激活、链接和关键操作。

## 色彩

| 角色 | Token | 建议值 |

## 尺寸与排版

- 左侧一级导航固定约 `74px`，白底，右边 `1px` 分隔线。
- 顶部工具栏高 `68px`，白底，底部有轻微阴影。
- 主内容最大阅读宽度约 `1180px`，桌面边距 `32px`，窄屏边距 `18px`。
- 标题使用中等字重，正文使用轻量无衬线；避免厚重的黑体标题和大面积大圆角。
- 基础圆角 `4px`，浮层圆角 `8px`，内容面板最多 `8px`。
- 间距基线采用 `4 / 8 / 12 / 16 / 24 / 32px`。

## 页面规则

- Articles 使用 5 列摄影网格，图片优先，作者链接为蓝色，日期为辅助灰。
- Blog 使用一张纵向特色封面配三列文章卡，相关内容以横向行展示。
- 一级导航保持图标化；悬浮后在侧边打开二级导航，不挤压主内容。
- 多表单页面使用链接型 Tabs；需要容器切换时才使用 JquanUI Tabs。
- 所有选择器、分页、素材库和认证反馈都使用 JquanUI 或共享主题样式。

## 响应式

- `>= 1280px`：保留窄侧栏、五列 Articles、四列 Blog 首屏结构。
- `768px - 1279px`：Articles 降为三列，Blog 降为两列。
- `< 768px`：侧栏转为顶端横向导航，摄影网格单列，特色文章改为横向可读布局。
- 图片固定使用 `aspect-ratio` 和 `object-cover`，避免加载时布局跳动。
